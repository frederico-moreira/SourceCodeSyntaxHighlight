# AGENTS.md

Fork of `sbarex/SourceCodeSyntaxHighlight` (Syntax Highlight 2.1.32, build 81). Goal: Quick Look previews for plist/xml/extensionless files without the "Syntax Highlight XPC Render ... buy me a coffee" footer.

Rules for agents: do not claim anything works without evidence (run URL, command output). Do not edit this file. Log results in `PROGRESS.md`.

## 1. Quick Look enablement
- Launch the built **Syntax Highlight.app** once so macOS discovers the Quick Look extension (System Settings > Extensions > Quick Look).
- The extension matches UTIs, not file extensions. In the app's main window enable the UTIs for `.plist`, `.xml` and "files without extension"/generic types.
- Reload Quick Look after changes: `qlmanage -r && qlmanage -r cache`.
- Size limit: M1 with 8 GB RAM, so set max data to about 1 MB in preferences. Larger blobs (for example 2-7 MB Chrome/Electron cache files) should fall back gracefully.

## 2. Footer removal: try WITHOUT rebuilding first
- Since 2.1.18: Settings > Advanced > uncheck the about/app info footer.
- Since 2.1.24: `syntax_highlight_cli` can show/hide the about footer.
- Only if both fail: patch `DocumentFooter` in `Application/resources/about.lua` so it returns an empty string, push, and let CI rebuild.

## 3. GitHub Actions build stack (verified)
Verified green: https://github.com/hypervanse/SourceCodeSyntaxHighlight/actions/runs/37986980064 (about 7 min, artifact about 18.8 MB).

- Runner: `macos-latest` (arm64, macOS 26.x, Xcode 26.x at test time).
- Quota: GitHub Free = 2,000 min/month. Public repos: standard runners (including macOS) are free and unlimited. Private repos: macOS bills at about 10x, so about 200 real minutes. Keep the fork public.
- Submodule: only `highlight-wrapper/highlight` (gitlab.com/saalen/highlight). Use `submodules: recursive`. Lua is compiled from it by the Xcode build; no Boost or brew steps needed.
- Swift packages: Sparkle 2.9.1 and Yams 6.2.1 must resolve (`-resolvePackageDependencies`).
- Scheme: `SyntaxHighlight` (builds target "Syntax Highlight"). There is NO scheme named "Syntax Highlight".
- Signing: use ad-hoc `CODE_SIGN_IDENTITY="-"`. An empty identity breaks `dos2unix`/`highlight-wrapper` makefiles (`codesign --sign ""` -> "no identity found").
- Xcode: `maxim-lobanov/setup-xcode@v1` with `xcode-version: latest-stable` (not `latest`, which may pick a beta).
- Workflow file: `.github/workflows/build.yml` (alongside this file). Trigger: push, pull_request, workflow_dispatch.
- Artifact: `Syntax-Highlight-app` (the .app). After download: `xattr -cr "Syntax Highlight.app"`, move to /Applications, launch once.

Run / watch / download:

```zsh
gh workflow run build.yml --ref master
gh run watch
gh run download -n Syntax-Highlight-app
```

Note: forks have workflows disabled by default. Enable via the Actions tab or `gh api -X PUT repos/OWNER/REPO/actions/permissions -F enabled=true`.

## 4. MCP servers for agy (Antigravity CLI)
`agy` reads this AGENTS.md. Add MCP servers with `agy mcp add` (flags before the name):

```zsh
# GitHub (official hosted server; no Docker). Token comes from gh; do not paste tokens into files.
agy mcp add --header "Authorization: Bearer $(gh auth token)" github https://api.githubcopilot.com/mcp/

# Obsidian: install the "Local REST API" plugin in Obsidian, copy its API key, then (verify package name first):
agy mcp add -e OBSIDIAN_API_KEY=<key> obsidian npx -y mcp-obsidian

agy mcp list
```

- `@modelcontextprotocol/server-github` is deprecated; use `github/github-mcp-server`.
- Start a new `agy` session after adding servers; use the account that owns the fork (`gh auth switch -u <account>`, then re-add).
- Models: `agy models` (not `--models`). Unattended runs: `agy --dangerously-skip-permissions --model <id> -i "<prompt>"`.
